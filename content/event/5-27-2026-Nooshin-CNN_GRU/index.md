summary: "This paper presents a lightweight deep learning framework for real-time stress monitoring using wearable physiological signals, specifically Blood Volume Pulse (BVP) and Electrodermal Activity (EDA). The proposed dual-branch CNN-GRU model combines convolutional layers for feature extraction with gated recurrent units for temporal pattern learning, enabling accurate stress detection while remaining suitable for resource-limited wearable devices. Evaluated on the WESAD dataset with subject-independent validation, the model achieved strong performance, including 99.27% accuracy, 99.97% F1-score, 99.68% AUC, and 98.40% Cohen’s kappa. The study also shows that sliding-window data augmentation helps address class imbalance and improves detection of stressed samples, highlighting the model’s potential for continuous, non-invasive stress monitoring in everyday settings."
